# Problem statement

## Client context

- **Delivery organisation:** Zynx Technologies Ltd
- **Domain client:** Banking Client
- **Engagement type:** Architecture & Advisory

## Business problem

The Banking Client required a repeatable medallion architecture and Unity Catalog security model so platform teams could standardise bronze/silver ingestion patterns, row/column controls, and workspace binding without reinventing governance for each domain.

## Success criteria (engagement)

- Clear architecture and ownership model
- Inspectable artefacts in Git (docs, diagrams, code/notebooks)
- Domain-safe documentation suitable for public portfolio audit
- Handover path for client engineering teams
